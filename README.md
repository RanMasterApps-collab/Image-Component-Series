# Jetpack Compose UI Components for Android

A collection of modern and reusable **Android UI components** designed in Canva and implemented using **Kotlin, Jetpack Compose, and Material 3**.

This repository provides ready-to-use UI components, custom illustrations, and source code created for modern Android app interfaces. Each component is designed with a focus on clean UI, reusable Composable functions, and practical Android development.

Step-by-step YouTube tutorials are also available for learning how each UI component is designed and implemented.

---

## 🎨 Canva → Jetpack Compose

The UI concepts and illustrations in this collection are designed in **Canva** and then recreated and implemented in **Jetpack Compose**.

The workflow is:

**Canva Design → UI Illustration → Jetpack Compose → Reusable Component → GitHub Source Code → YouTube Tutorial**

This approach helps turn visual UI ideas into practical and reusable Android components.

# 🚀 How to Use

1. Open the component folder you need.
2. Open the corresponding Kotlin source file.
3. Copy the required Composable functions into your Android project.
4. Add the required imports and dependencies.
5. Add any required drawable resources or illustrations.
6. Customize the colors, text, icons, and dimensions.
7. Run the component in your Jetpack Compose project.
